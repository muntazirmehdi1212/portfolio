# Muntazir Mehdi — AI & Machine Learning Portfolio

Personal portfolio of **Muntazir Mehdi**, final year BS Mathematics student at Bahauddin Zakariya University, Multan (CASPAM), building practical AI, machine learning and Python applications.

The whole website is a single self-contained file: `index.html`.

## Projects

- **AI-Based Optimization Solver System** — linear programming, KKT conditions, genetic algorithm, transportation problem and gradient descent, with an interactive demo that runs in the browser
- **Smart Inventory ML** — inventory, billing and demand prediction with a stockout-risk Decision Tree
- **Smart CV Generator** — Gradio app that creates a CV as a PDF
- **LinkedIn Post Creator Pro** — AI writing assistant for LinkedIn posts
